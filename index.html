Workflow & Prompt Library

After each session, practical takeaways get written up and added to a members-only repository, maintained by the YLS AI Committee, so the group's working knowledge compounds instead of evaporating after the panel ends.

How an entry gets here

Every workflow that makes it into the library has been named, tried, and checked before it's shared.

  1. Learn. A practitioner or session panelist demonstrates a real task and its risks.
  2. Try it. Members work the same task and note what actually happened, not just the theory.
  3. Check it. A confidentiality, accuracy, and usability pass before anything gets shared further.
  4. Add to the library. A short, dated write-up joins this page for other members to reuse.
